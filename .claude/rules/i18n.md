# Dictionnaires

- `fr.ts` est la source ; `ca.ts` lui répond clé pour clé. Après toute clé
  ajoutée ou retirée : `npx tsx scripts/verifier-dictionnaire.ts` (zéro défaut).
- Pas de balisage dans une chaîne ; pluriel par `Intl.PluralRules` ; la
  ponctuation appartient à la langue (espace insécable avant « : » en français).
- Catalan standard, vocabulaire Termcat, aucune tournure rossellonaise inventée.
  Détail : `docs/i18n.md`.
