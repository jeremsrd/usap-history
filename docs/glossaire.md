# Glossaire

Vocabulaire du projet. Les faits (palmarès, stades, dates) sont dans la base,
pas ici.

| Terme | Sens dans ce projet |
|---|---|
| USAP | Union Sportive Arlequins Perpignanais ; « le camp catalan », `isOpponent: false` |
| LNR | Ligue nationale de rugby — source officielle du championnat (Top 14, Pro D2, Top 16, barrages) |
| EPCR / ERC | organisateur des coupes d'Europe (depuis 2014 / avant) — source officielle des coupes |
| Feuille de match | composition des 23 (22 avant 2008-2009), faits et changements d'une rencontre |
| Couperet | match à élimination (phase finale, barrage, finale) : pas de bonus |
| BO / BD | bonus offensif / défensif (barème par époque, `docs/regles-du-jeu.md`) |
| Carton orange | carton du championnat français : joueur exclu, poste repourvu après 20 min ; équivaut au rouge de 20 min européen |
| Essai de pénalité | sans auteur ; compté 7 points en base à toute époque (transformation comprise) |
| Essai collectif, « n.a. » | points que la LNR n'attribue à personne : légitimes, la somme des joueurs tombe sous le score |
| Titulaire / remplaçant | n° 1-15 / 16-23 ; le poste d'un remplaçant reprend `Player.position` |
| Centurion | joueur à 100 matchs ou plus sous le maillot catalan |
| Attestation | provenance d'un fait hors feuille officielle ; degrés OFFICIEL, CONCORDANT, PROBABLE, ARBITRE |
| Variante d'affichage | même homme, nom d'usage en base, état civil sur la feuille (`VARIANTES_DAFFICHAGE`) |
| Nom d'usage | deux écritures d'un homme que rien ne rapproche (`NOMS_DUSAGE`) |
| Marche du lendemain | la chaîne de scripts après un match de la saison en cours |
